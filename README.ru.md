🛡️ Aegis Funding Vault (На русском)🌐 НавигацияLooking for the English version?🇬🇧 Read the main documentation here📝 Описание проектаAegis Funding Vault помогает распределять и выдавать целевые средства (гранты, стипендии, бюджеты акселераторов или контролируемые выплаты командам) не вручную, а по прозрачным, автоматизированным правилам.Главная мысль проекта:Деньги не уходят из пула мгновенно. Сначала система обрабатывает запрос, проверяет его с помощью ИИ-агента, пропускает через жесткие бэкенд-правила, и только после этого выносит финальное решение в блокчейн.Как это работает простыми словами:Депозит: Фаундер создает контракт (vault) и кладет туда SOL.Запрос: Получатель отправляет запрос на расход с детальным описанием цели.ИИ-валидация: Сервер отправляет запрос на проверку через Gemini API.Проверка правил: Бэкенд сопоставляет вердикт ИИ с жесткими системными ограничениями (бэкенд не верит нейросети вслепую).Запись в блокчейн: Решение (Approve/Reject) отправляется в сеть Solana, и статус обновляется.Безопасный режим: Если ИИ недоступен, автоматически включается запасной режим ручной или регламентированной проверки.🛠 Структура репозиторияДиректорияТехнологииОписаниеprograms/aegis_vaultRust / AnchorСмарт-контракт. 2. Сборка и тестирование смарт-контрактаBashanchor build
anchor test
3. Настройка окружения (.env)Скопируйте шаблоны конфигурации в папках backend и frontend:Bashcp packages/backend/.env.example packages/backend/.env
cp packages/frontend/.env.example packages/frontend/.env
⚠️ What to fill in .env on the backend:GEMINI_API_KEY — твой ключ ИИ Gemini.SOLANA_RPC_URL — адрес ноды сети.RISK_AUTHORITY_SECRET_KEY — приватный ключ для подписи решений.PROGRAM_ID — адрес развернутого контракта.4. Запуск приложенийЗапуск бэкенда:Bashnpm run dev:backend
Запуск фронтенда:Bashnpm run dev:frontend
